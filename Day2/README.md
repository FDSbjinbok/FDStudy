# IEEE 754 부동소수점 표준

## 1. IEEE 754란?

IEEE 754는 컴퓨터에서 실수를 **부동소수점(floating point)** 형식으로 저장하고 연산하는 방법을 정한 국제 표준입니다. 부동소수점은 실수를 **과학적 표기법**처럼 저장합니다. 10진수 `6.25 = 6.25 × 10⁰`을 2진수로 바꾸면 `1.1001 × 2²`와 같은 형태가 됩니다.

### 구성 요소

어떤 실수든 다음 세 부분으로 나누어 저장합니다.

| 구성 요소 | 의미 |
|---|---|
| **부호(Sign)** | 0이면 양수, 1이면 음수 |
| **지수(Exponent)** | 2의 몇 제곱인지. 바이어스(bias)를 더해서 저장 |
| **가수(Mantissa / Fraction)** | `1.xxxx`에서 소수점 뒤의 `xxxx` 부분 |

### 정밀도별 비트 구성

| 형식 | C# 타입 | 전체 | 부호 | 지수 | 가수 | Bias |
|---|---|---|---|---|---|---|
| 단정밀도 | `float` | 32비트 | 1 | 8 | 23 | 127 |
| 배정밀도 | `double` | 64비트 | 1 | 11 | 52 | 1023 |

값은 다음 공식으로 계산합니다.

> **값 = (−1)^부호 × 1.가수 × 2^(지수 − bias)**

### 핵심 개념 두 가지

**정규화와 숨은 비트(Hidden bit):** 2진수를 정규화하면 맨 앞자리는 항상 `1`입니다(`1.xxx × 2ⁿ`). 그래서 이 `1`은 저장하지 않고 생략합니다. 23비트만 저장해도 실제로는 24비트의 정밀도를 얻는 셈입니다.

**바이어스(Bias):** 지수는 음수가 될 수 있습니다(예: 0.25 = 1.0 × 2⁻²). 부호 비트를 따로 두지 않고, 실제 지수에 127을 더해 0~255 범위의 양수로 저장합니다. 이렇게 하면 비트 패턴을 정수처럼 비교해도 크기 순서가 유지되는 장점이 있습니다.

### 특수값

| 지수 비트 | 가수 비트 | 의미 |
|---|---|---|
| 모두 0 | 0 | ±0 (양의 0과 음의 0이 따로 존재) |
| 모두 0 | 0이 아님 | 비정규화 수(Denormal): 0에 매우 가까운 아주 작은 수 |
| 모두 1 | 0 | ±무한대 (Infinity) |
| 모두 1 | 0이 아님 | NaN (Not a Number) |

## 2. 6.25를 float 비트로 표현하기

### Step 1: 정수부를 2진수로 변환
6 → `110`
(6÷2=3 나머지 0, 3÷2=1 나머지 1, 1÷2=0 나머지 1 → 나머지를 거꾸로 읽음)

### Step 2: 소수부를 2진수로 변환
소수부에 2를 계속 곱하면서, 정수부로 넘어온 자리를 차례로 읽습니다.
```
0.25 × 2 = 0.5  → 0
0.5  × 2 = 1.0  → 1  (소수부가 0이 되었으므로 종료)
```
0.25 → `.01`

### Step 3: 합치기
6.25 = `110.01₂`

### Step 4: 정규화
소수점을 왼쪽으로 2칸 옮깁니다.
`110.01 = 1.1001 × 2²`

### Step 5: 각 필드 결정
- **부호:** 양수이므로 `0`
- **지수:** 2 + 127 = 129 → `10000001`
- **가수:** 맨 앞의 `1.`을 뺀 `1001`을 쓰고, 나머지 23비트를 0으로 채움 → `10010000000000000000000`

### Step 6: 결과

```
부호   지수        가수
 0   10000001   10010000000000000000000
```

4비트씩 끊어 16진수로 바꾸면 다음과 같습니다.
```
0100 0000 1100 1000 0000 0000 0000 0000
  4    0    C    8    0    0    0    0    →  0x40C80000
```

**검증:** (−1)⁰ × 1.1001₂ × 2^(129−127) = 1.5625 × 4 = **6.25** ✅

반대로 `uint` 비트 패턴을 받아서 공식 `(−1)^s × 1.m × 2^(e−127)`으로 실수 값을 계산하세요. 이때 `BitConverter.Int32BitsToSingle`은 사용하지 않습니다.
- `DecodeFloat(0x40C80000)` → `6.25`
- `DecodeFloat(0xC1560000)` → `-13.375`
